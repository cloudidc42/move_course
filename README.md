# หลักสูตร Move Programming Language
## ตั้งแต่ระดับพื้นฐาน จนถึง ระดับมืออาชีพ และ ระดับโลก

---

## เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ครอบคลุมการเขียนโปรแกรมด้วยภาษา **Move** ซึ่งเป็นภาษาที่พัฒนาโดย Meta (Facebook) สำหรับ Blockchain ที่ปลอดภัยสูง โดยมีการประยุกต์ใช้บน:

- **Aptos Blockchain** - Blockchain รุ่นใหม่ที่ปลอดภัยและรวดเร็ว
- **Sui Blockchain** - Blockchain ที่เน้น Object-centric model
- **Move VM** - Virtual Machine สำหรับ Move Language

## วิธีการเรียน

1. **เรียนตามลำดับ** - เริ่มจาก Part 1 และไปเรื่อยๆ
2. **ทำ Exercise** - แต่ละ Part มี exercises ให้ฝึก
3. **ทำ Projects** - มี projects ให้ทำในแต่ละระดับ
4. **อ่าน Code จริง** - ตัวอย่างทั้งหมดเป็น code ที่ใช้งานได้จริง

## Requirements

- ความรู้พื้นฐานการเขียนโปรแกรม (ภาษาใดก็ได้)
- ความเข้าใจพื้นฐานเกี่ยวกับ Blockchain (ไม่จำเป็นต้องลึกมาก)
- Aptos CLI หรือ Sui CLI (ติดตั้งตาม Part 02)
